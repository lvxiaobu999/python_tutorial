# 04.1 · 数据库集成（SQLModel + Alembic）

> 练习代码：[01-数据库.py](../../projects/04-fastapi进阶/04.1-数据库集成/01-数据库.py) ｜ Alembic 实操记录：[章节 README](../../projects/04-fastapi进阶/04.1-数据库集成/README.md) 第 5 节

## 核心概念

- **SQLModel = Pydantic + SQLAlchemy 合体**：一个类身兼两职——默认是校验模型（03.3），加 `table=True` 升级为真表。公共字段写进 `BookBase`，`Book(table=True)` 和 `BookCreate` 各取所需。
- **三件套分工**：
  - `engine`：连接工厂，模块级单例（全应用一份，04.5 的 ConnectionManager 同套路）；
  - `Session`：工作单元——改动先记在 session 里，`commit()` 才落库；
  - `select()`：查询构建器，`.where()/.offset()/.limit()` 翻译成 SQL——过滤和翻页是**数据库**挑行，不是拉全表回 Python 切片。
- **yield 依赖第一个真实用例**：`get_session` yield 前开会话、finally 关会话——路由哪怕抛 404 也保证关闭。
- **create_all 的盲区**：只发 `CREATE TABLE`、表已存在就整体跳过，永远不发 `ALTER TABLE`——改已有表结构必须用迁移工具（Alembic）。

## 关键代码

```python
class Book(BookBase, table=True):           # table=True：类 → 真表
    id: int | None = Field(default=None, primary_key=True)  # 数据库自增，客户端不传

def get_session():                          # yield 依赖：setup / teardown
    session = Session(engine)
    try:
        yield session
    finally:
        session.close()

SessionDep = Annotated[Session, Depends(get_session)]

@app.post("/books", status_code=201)
def create_book(data: BookCreate, session: SessionDep) -> Book:
    book = Book.model_validate(data)
    session.add(book)      # 入队
    session.commit()       # 落库（忘了 = 白忙一场）
    session.refresh(book)  # 回填数据库生成的 id（见常见坑 1）
    return book
```

## 运行结果

- `uv run fastapi dev "04.1-数据库集成/01-数据库.py"` → 目录下出现 `books.db`；
- POST 建书 → 重启服务 → GET 还在：这就是「持久化」；
- PATCH 改价 → 200 + 更新后的书；rating 传 6 → 422（Pydantic 校验还在站岗）。

## 常见坑

1. **commit 后返回 `{}`**：`expire_on_commit=True` 默认把对象属性清出内存，而 FastAPI 序列化直接读对象属性、不触发惰性加载 → 必须 `session.refresh(book)`。
2. **select 链式调用不生效**：`.where()` 返回**新**查询对象，必须 `query = query.where(...)` 接住返回值——和字符串不可变一个道理。
3. **可选查询参数 `= None` 不能省**：省了 `author: str | None = None` 的默认值，参数就从可选变必填。
4. **check_same_thread=False**：SQLite 默认禁止跨线程复用连接，而 def 路由跑在线程池、每请求可能换线程。
5. **`Sequence[Book]` ≠ `list[Book]`**：`.all()` 的静态类型是 Sequence，`list()` 包一层兑现 `list[Book]` 的注解承诺。
6. **Alembic 三坑**（实操复盘见章节 README）：
   - 命令要带 `uv run` 前缀（venv 不在 PATH，`alembic` 单敲必报「无法识别」）；
   - ini 按 Windows 本地编码（GBK）读取 → **保持纯 ASCII**，数据库 URL 在 `env.py` 里配（Python 文件是 UTF-8）；
   - **加列铁律**：给有数据的表加列，必须可空或带默认值，否则迁移执行必挂。
