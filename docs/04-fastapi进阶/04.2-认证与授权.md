# 04.2 · 认证与授权（bcrypt + JWT）

> 练习代码：[02-认证.py](../../projects/04-fastapi进阶/04.2-认证与授权/02-认证.py)

## 核心概念

- **认证 ≠ 授权**：认证回答「你是谁」（验密码/token），授权回答「你能干啥」（比对角色）。HTTP 语义上分别对应 401 和 403。
- **HTTP 无状态** → 每次请求都要自带凭证：请求头 `Authorization: Bearer <token>`（03.4 Header 的真用场）。
- **密码哈希（bcrypt）**：单向不可逆，只能「验」不能还原；`gensalt` 随机盐让同一密码每次哈希都不同，彩虹表（预计算指纹库）失效。库里只存哈希，不存明文。
- **JWT 三段式** `header.payload.signature`：服务器用 SECRET_KEY 对前两段重算签名比对——**改一个字节都骗不过**。payload 只放 `sub`（谁）和 `exp`（活到几点），绝不放密码等敏感信息。
- **OAuth2PasswordBearer**：自动从请求头抠 token（没带 → 401）；`tokenUrl="login"` 是说给 /docs 听的 → 右上角出现 Authorize 按钮。
- **依赖链分层**：`oauth2_scheme`（抠 token）→ `get_current_user`（验签 + 查库）→ `require_admin`（角色不够 → 403）——03.5 依赖链的真实版。

## 关键代码

```python
def create_token(username: str) -> str:
    payload = {"sub": username, "exp": int(time.time()) + ACCESS_TOKEN_EXPIRE}
    return jwt.encode(payload, SECRET_KEY, algorithm=ALGORITHM)

def get_current_user(token: Annotated[str, Depends(oauth2_scheme)]) -> dict:
    try:
        payload = jwt.decode(token, SECRET_KEY, algorithms=[ALGORITHM])  # 显式验算法 + exp 到期一并拦
    except jwt.InvalidTokenError:               # 篡改 / 过期 / 格式损坏，统统进这里
        raise HTTPException(401, detail="token 无效或已过期")
    user = fake_users_db.get(payload["sub"])    # 权限以库为准：改角色不用重登
    if user is None:
        raise HTTPException(401, detail="用户不存在")
    return user

def require_admin(user: Annotated[dict, Depends(get_current_user)]) -> dict:
    if user["role"] != "admin":
        raise HTTPException(403, detail="需要管理员权限")
    return user
```

## 运行结果

- /docs 点右上角 Authorize 登录 → 带锁接口自动带上 Authorization 头；
- 删除接口自测三连：匿名 → 401，li（reader）→ 403，zhang（admin）→ 200；
- token 改一个字符再访问 → 401（签名对不上）；有效期改 1 秒、睡 2 秒再访问 → 401（`ExpiredSignatureError`）。

## 常见坑

1. **`sub` 写死**（本次真实踩过）：`create_token` 里 payload 写死 `"zhangsan"`，username 参数形同虚设——登录签出来的 token 查库查不到人，**所有**受保护接口全 401。`sub` 必须是「正在登录的那个人」。
2. **登录失败话术统一**：用户名不存在和密码错误给同一句「用户名或密码错误」——分开提示等于向攻击者暗示「这个用户名是存在的」。
3. **SECRET_KEY 不能写死提交 git**：谁拿到密钥谁就能伪造 token；真实项目从环境变量读。
4. **401 / 403 别混用**：没登录、凭证坏 → 401；登录了但角色不够 → 403。
