# 04.5 · WebSocket 与流式（SSE）

> 练习代码：[05-流式.py](../../projects/04-fastapi进阶/04.5-websocket与流式/05-流式.py) ｜ 演示页：同目录 index.html

## 核心概念

- 之前的接口都是**一问一答**：return 一次连接就结束。本章学两种「持续说话」：
  - **WebSocket**：双向长连接（聊天室、协同编辑）；
  - **SSE**：服务器单向推（AI 打字机效果的骨架）。
- **WebSocket 要点**：`@app.websocket` 路由；`accept()` 握手后连接才真正建立；`while True` 保活（不循环回一条就退出，退化成普通请求-响应）；`receive_text()` 没消息时挂起等待；断线抛 `WebSocketDisconnect` = 正常下班，不是故障。
- **广播的本质**：WebSocket 只能一对一说话；「群发」= 自己攥一份在线名单（`ConnectionManager`），挨个 `send_text`。模块级单例全应用共享（04.1 engine 同套路）。
- **SSE 三要素**：`data: ` 开头；`\n\n`（两个换行）才是一条消息的终点；`StreamingResponse` + async 生成器——**yield 一块发一块**，绝不攒齐再给。

## 关键代码

```python
@app.websocket("/ws/chat")
async def chat(ws: WebSocket) -> None:
    await manager.connect(ws)                 # 握手 + 上名单
    try:
        while True:
            text = await ws.receive_text()    # 挂起等待
            await manager.broadcast(text)     # 全场群发
    except WebSocketDisconnect:
        manager.disconnect(ws)                # 销户（同步方法：列表增删不需 await）
        await manager.broadcast("（一位朋友离开了聊天室）")

async def book_stream():                      # async 生成器 = 02.3 yield + 02.5 await 合体
    for title in BOOKS:
        await asyncio.sleep(0.5)              # 真实场景：卡在调模型吐 token
        yield f"data: 《{title}》\n\n"
```

## 运行结果

- `uv run fastapi dev ...` 后浏览器开 http://127.0.0.1:8000/（/docs 调试不了 WebSocket）；
- 多开几个页面互发：任何人发言全场可见，终端实时打印在线人数变化；
- /books/stream 在页面里逐条蹦出来，最后一条「共 5 本」。

## 常见坑

1. **/docs 调不了 WebSocket**：OpenAPI 只描述「请求-响应」，长连接不归它管。
2. **broadcast 要遍历副本**：`for ws in self.active.copy()`——await 的间隙可能有人断线销户，边遍历边改名单会乱套。
3. **SSE 少写 `\n\n`**：一条消息永远「没说完」，前端 EventSource 不触发。
4. **index.html 必须从服务器地址打开**（同源）：双击文件用 file:// 打开，EventSource 会被浏览器同源策略拦——跨域放行是 04.3 CORS 的主题。
