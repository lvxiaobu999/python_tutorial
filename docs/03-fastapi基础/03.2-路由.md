# 03.2 · 路由：路径、查询、请求体与 APIRouter

> 练习代码：[02-路由.py](../../projects/03-fastapi基础/03.2-路由/02-路由.py)

## 核心概念

- **路由 = 「什么请求」交给「哪个函数」**。URL 里能装的信息有三处：路径（定位资源）、查询串（过滤/开关）、请求体（提交数据），加上拆分大项目的 APIRouter，就是本章全部。
- **路径参数**：`{item_id}` 占位符与参数**同名**即可接住；注解决定行为——`int` 自动把 `"3"` 转成 `3`，传 `abc` 直接 422；`str` 原样接收不转换。
- **路径顺序先注册先匹配**：固定路径 `/users/me` 必须写在通配路径 `/users/{user_id}` **前面**，否则 `me` 被当成 `user_id` 吃掉。
- **查询参数**：不在路径占位符里的函数参数自动成为查询参数；有默认值即可选，没有即必填；`bool` 自动转换（`?active=false` → `False`，还认 `"1"/"0"/"yes"/"no"`）。
- **请求体**：参数类型是 Pydantic `BaseModel` 时，FastAPI 把请求体 JSON 校验后传进来（03.3 细讲）。
- **APIRouter**：`prefix` 统一加前缀、`tags` 在 /docs 里分组；大项目标准结构是一个业务模块一个 router，各自成文件，最后 `include_router` 挂回主应用。

## 关键代码

```python
@app.get("/items/{item_id}")            # 占位符与参数同名
def get_item(item_id: int) -> dict:     # 注解 int：自动转换 + 校验
    return {"item_id": item_id}

@app.get("/books")                       # 不在路径里的参数 → 查询参数
def list_books(author: str | None = None, in_stock: bool = True) -> dict:
    return {"author": author, "in_stock": in_stock}

router = APIRouter(prefix="/shop", tags=["商店"])  # 前缀 + 文档分组

@router.get("/goods")                    # 实际路径是 /shop/goods
def list_goods() -> dict:
    return {"goods": ["键盘", "鼠标"]}

app.include_router(router)               # 挂回主应用
```

## 运行结果

- `/items/3` → `{"item_id": 3}`；`/items/abc` → 422 校验错误（注解在把关）；
- `/books?author=鲁迅&in_stock=false` → `in_stock` 自动转成 `False`；
- `/users/me` 命中固定路径（它注册在前）；PUT `/users/1/items/2?q=x` 里路径参数和查询参数各归各位；
- /docs 观察点：每个接口的参数被自动识别并生成表单；商店接口归在「商店」tag 分组下。

## 常见坑

1. **占位符和参数名不一致**：路径写 `{item_id}` 参数就得叫 `item_id`，写 `{id}` 就接不到。
2. **`/users/me` 注册在 `/users/{user_id}` 之后**：先注册先匹配，写反了 `me` 会被当成 `user_id`。
3. **路径漏开头的 `/`**：`@app.get("items")` 直接报错，必须 `"/items"`。
4. **用浏览器地址栏测 POST**：地址栏只会发 GET——去 /docs 用 Try it out。
5. **查询参数不给默认值**：`keyword: str` 变成必填，客户端不传就 422。
