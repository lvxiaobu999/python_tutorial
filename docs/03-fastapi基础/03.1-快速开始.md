# 03.1 · 快速开始：第一个 API 与自动文档

> 练习代码：[01-快速开始.py](../../projects/03-fastapi基础/03.1-快速开始/01-快速开始.py)

## 核心概念

- **FastAPI 的本质**：把函数签名上的类型注解翻译成三样东西——校验规则、接口文档、JSON 序列化。你在 02.4 手写的注解从这里开始自动干活，这是它和 Flask 最本质的差别。
- **两块地基各管一层**：Starlette 管 Web 层（路由、请求/响应、中间件）；Pydantic 管数据层（校验、序列化、schema 生成）。
- **起服务的是 uvicorn（ASGI 服务器）**：它才真正监听端口、跑事件循环；FastAPI 只是 import 进来的库，`app` 不会自己起服务。
- **固定结构三角色**：装饰器定「在哪」（HTTP 方法 + 路径），路径操作函数定「干什么」，返回值就是「响应体」。
- **自动文档白送**：`/docs`（Swagger UI，可交互）、`/redoc`（阅读排版）、`/openapi.json`（两者的数据源）——文档 = 注解 + docstring 的影子。
- **返回值不挑食**：dict / list / str / int 直接返回自动 JSON 化；精确控制响应头/状态码要等 03.4 的 `Response`。

## 关键代码

```python
from fastapi import FastAPI

app = FastAPI(title="我的第一个 API")  # title 显示在 /docs 页面标题上

@app.get("/")          # ② 路径操作装饰器：HTTP 方法 + 路径
def root() -> dict:    # ③ 路径操作函数：这次请求怎么处理
    """docstring 支持 Markdown，会渲染进 /docs。"""
    return {"message": "你好，FastAPI"}  # ① 应用实例身上挂着所有路由；dict 自动变 JSON
```

## 运行结果

```bash
uv run fastapi dev "03.1-快速开始/01-快速开始.py"
```

- 浏览器访问 `http://127.0.0.1:8000/` → `{"message":"你好，FastAPI"}`；
- `/docs` 观察点：接口列表、docstring 渲染、Try it out 直接发请求；`/redoc` 是同一份信息的阅读排版；
- 改代码保存自动重载，`/docs` 里同步出现新接口。

## 常见坑

1. **`python 01-快速开始.py` 没反应**：它只「定义 app」然后退出，起服务是 uvicorn 的活——用 `fastapi dev` 跑。
2. **改了代码没生效**：确认 `fastapi dev` 还开着（它才自动重载）；用 uvicorn 裸跑要手动加 `--reload`。
3. **浏览器地址栏测不了 POST/PUT**：地址栏只会发 GET——去 `/docs` 用 Try it out。
4. **装饰器路径漏开头的 `/`**：`@app.get("items")` 直接报错，必须写 `"/items"`。
5. **`async def` 路由里写 `time.sleep(3)` 卡住整个服务**：阻塞了事件循环——要么 `await asyncio.sleep()`，要么写成普通 `def`（FastAPI 会自动丢进线程池，不卡别人）。
