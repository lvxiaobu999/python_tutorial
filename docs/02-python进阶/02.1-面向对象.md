# 02.1 · 面向对象

> 练习代码：[01-类与继承.py](../../projects/02-python进阶/02.1-面向对象/01-类与继承.py)、[02-魔术方法与dataclass.py](../../projects/02-python进阶/02.1-面向对象/02-魔术方法与dataclass.py)

## 核心概念

- **类是图纸，实例是产品**：`Dog("旺财")` 时 `__init__` 自动调用；`self` 就是「这个实例自己」，调用 `dog.bark()` 等价于 `Dog.bark(dog)`，不用手动传。
- **类属性 vs 实例属性**：类属性所有实例共享一份（如 `BankAccount.account_count` 统计开户数），实例属性每个对象各一份；找属性的顺序是先实例、再类。
- **三种方法**：普通方法收 `self`（读写实例数据）；`@classmethod` 收 `cls`（当替代构造器，如 `Date.from_string`）；`@staticmethod` 什么都不收（和类相关的纯函数）。
- **继承与多态**：`super().__init__(...)` 委托父类初始化；同一个 `speak()` 调用放进循环，不同对象各自执行自己的版本——这就是多态。
- **鸭子类型**：Python 多态不检查类型、只检查行为，对象只要有 `speak()` 就能进循环，哪怕与父类毫无继承关系（练习里的 `Robot`）。
- **魔术方法与 dataclass**：`__add__`/`__eq__`/`__len__`/`__getitem__` 让自定义对象支持 `+`、`==`、`len()`、下标、`for`；`@dataclass` 一个装饰器生成 `__init__`/`__repr__`/`__eq__` 三段样板——FastAPI 的 Pydantic 模型就是加强版 dataclass。

## 关键代码

```python
class Dog:
    kind = "犬科"                          # 类属性：所有实例共享一份

    def __init__(self, name: str):
        self.name = name                   # 实例属性：每个实例各一份

    def speak(self) -> str:                # 子类可重写，循环里自动多态
        return f"{self.name}：汪！"


class Robot:                               # 故意不继承 Dog：鸭子类型照样能进循环
    def speak(self) -> str:
        return "哔哔"


for obj in [Dog("旺财"), Robot()]:         # 只检查「有没有 speak」
    print(obj.speak())


from dataclasses import dataclass, field

@dataclass                                  # 自动生成 __init__/__repr__/__eq__
class Book:
    title: str
    tags: list[str] = field(default_factory=list)  # 可变默认值的正确写法

print(Book("Python进阶") == Book("Python进阶"))
```

## 运行结果

```text
旺财：汪！
哔哔
True
```

`Vector2D` 演示：`v1 + v2` 触发 `__add__` 得 `Vector2D(4, 6)`，`print` 触发 `__repr__`，`abs(v1)` 触发 `__abs__` 得 5.0（3-4-5 直角三角形）。

## 常见坑

- **可变类属性被所有实例共享**：`class C: items = []` 后实例往里 append，改的是同一份列表——实例自己的可变数据必须在 `__init__` 里 `self.items = []`。
- **子类 `__init__` 忘写 `super().__init__(...)`**：父类属性没被初始化，后续方法用到时才报 `AttributeError`。
- **dataclass 可变默认值写 `tags = []`**：直接报 `ValueError: mutable default`，要用 `field(default_factory=list)`，让每个实例各新建一个列表。
- **没写 `__eq__` 时 `==` 比的是内存地址**：内容相同的两个对象也返回 False；另外与其他类型比较要返回 `NotImplemented`，否则 `Money(8) == 8` 会抛 `AttributeError`。
- **实例方法第一个参数忘写 `self`**：调用时报参数数量不匹配。
