# 02.4 · 类型注解

> 练习代码：[01-类型注解.py](../../projects/02-python进阶/02.4-类型注解/01-类型注解.py)

## 核心概念

- **注解是写给人和工具看的契约**：IDE 靠它补全跳转、pyright/mypy 靠它静态查错、团队协作不用翻实现。读懂注解，才能看懂 FastAPI 路由函数的每一个字符。
- **关键认知：注解默认不影响运行**——`def f(x: int)` 传 `"abc"` 照样跑；要真正检查需跑 `uv run pyright`。FastAPI 是特例：它读取注解在运行时校验请求参数、生成文档。
- **容器类型 3.9+ 直接用内置**：`list[int]`、`dict[str, int]`、`tuple[int, str]`（固定长）/ `tuple[int, ...]`（不定长）；`typing.List` 是老写法。
- **`Optional[str]` / `str | None`**：意思是「str 或 None」，三种写法等价；3.10+ 优先用 `|`。
- **鸭子类型注解**：参数用 `Iterable[int]`、`Callable[[int, int], int]`、`Mapping[str, int]` 比 `list`/`dict` 更宽容——「参数宽松、返回精确」是好习惯。
- **泛型与 TypedDict**：`def first_of[T](items: list[T]) -> T` 写一次类型处处套用；`TypedDict` 给固定结构的字典上类型（LangGraph 的 State 就是这么定义的）。

## 关键代码

```python
type ScoreTable = dict[str, list[float]]       # 3.12+ 类型别名


def average(table: ScoreTable, student: str) -> float | None:
    """返回 float 或 None（找不到该学生时）。"""
    scores = table.get(student)
    if scores is None:
        return None
    return sum(scores) / len(scores)


class Box[T]:                                  # T 是类型占位符，实例化时才确定
    def __init__(self, item: T) -> None:
        self.item = item

    def get(self) -> T:                        # 放进去什么，取出来就是什么
        return self.item


box = Box("三体")                              # 推断为 Box[str]
print(box.get().upper())                       # 工具知道返回值是 str，补全可用
```

## 运行结果

```text
三体
```

练习实测：`price(100, 2.5)` 的 `count` 注解是 `int`，传 float 运行时不报错——要靠 pyright 抓；`set_mode("up")` 运行时能跑，但 pyright 会标红 `Literal["dev", "prod"]` 之外的字面量。

## 常见坑

- **以为注解会运行时强制检查**：传错类型照样跑；想检查要装 `uv add --dev pyright` 后 `uv run pyright`。
- **把 `Optional[int]` 当成「参数可省略」**：可不可省略由默认值决定（`x: int = 0`）；`x: int | None = None` 才表示「默认 None，传就必须是 int 或 None」。
- **写裸的 `list`、`dict` 不带参数**：能匹配任何列表，信息量为零，要写 `list[int]`。
- **还在用 `typing.List` / `typing.Dict` 老写法**：3.9+ 一律 `list[int]` / `dict[str, int]`。
- **`Any` 满天飞**：等于放弃检查，实在没辙再用（如和 json 打交道时逐步收窄）。
- **注解了却从不跑检查工具**：注解就只是注释，组合拳是「注解 + pyright」。
