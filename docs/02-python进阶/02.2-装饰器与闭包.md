# 02.2 · 装饰器与闭包

> 练习代码：[01-闭包与装饰器.py](../../projects/02-python进阶/02.2-装饰器与闭包/01-闭包与装饰器.py)

## 核心概念

- **闭包**：内层函数引用了外层函数的变量、且被返回出去——变量就和函数一起「被打包」带走，不随外层函数结束而消失（`make_counter` 的 `count`）。函数从此自带「出厂设置」，不需要全局变量。
- **装饰器本质**：接收函数、返回新函数的高阶函数；`@x` 只是 `f = x(f)` 的语法糖。把计时、日志、重试这类横切逻辑从业务代码里抽出来。
- **装饰发生在 `def` 执行的那一刻**（import 时），不是调用时；所以执行逻辑必须写在最内层 `wrapper` 里。
- **`@functools.wraps(func)` 几乎必加**：把原函数的 `__name__`、`__doc__`、报错堆栈抄给 wrapper，否则调试时满屏 `wrapper`。
- **带参数的装饰器 = 三层函数**：第一层收装饰器参数、第二层收被装饰函数、第三层才真正执行；`@repeat(3)` 比 `@repeat` 多一层括号。
- **多个装饰器是洋葱模型**：`@a` 在 `@b` 上方等价于 `f = a(b(f))`——装饰从下往上包，执行从上往下进。
- 常用现成货：`@functools.lru_cache` 按参数缓存结果（练习里 fib(32) 从几百万次调用降到 33 次），`@property`/`@dataclass`/`@pytest.fixture` 也都是装饰器。

## 关键代码

```python
import functools
import time


def timer(func):
    @functools.wraps(func)                 # 保留原函数元信息
    def wrapper(*args, **kwargs):          # *args/**kwargs 接住任意参数
        start = time.perf_counter()
        result = func(*args, **kwargs)     # 必须 return，否则返回值丢了
        print(f"函数 {func.__name__} 耗时 {time.perf_counter() - start:.3f} 秒")
        return result

    return wrapper


@timer                                     # 等价于 slow_sum = timer(slow_sum)
def slow_sum(n):
    time.sleep(0.3)
    return sum(range(n))


def repeat(times):                          # 带参数装饰器：三层
    def decorator(func):
        @functools.wraps(func)
        def wrapper(*args, **kwargs):
            for _ in range(times):
                result = func(*args, **kwargs)
            return result

        return wrapper

    return decorator
```

## 运行结果

```text
slow_sum(10_000) → 先打印「函数 slow_sum 耗时 0.3xx 秒」，再返回 49995000
@repeat(times=3) 装饰的 ping() → 连打三次 pong，且 ping.__name__ 仍是 "ping"
```

## 常见坑

- **`return counter` 写成 `return counter()`**：前者返回函数本身（对），后者立刻执行并返回结果（错）。
- **wrapper 忘记 `return func(...)`**：被装饰函数的返回值变成 `None`。
- **忘记 `@functools.wraps`**：`f.__name__` 变成 `wrapper`，多个被装饰函数的报错堆栈难以区分。
- **`@repeat` 与 `@repeat(3)` 混淆**：定义了三层却写 `@repeat`，会把函数本身当成装饰器参数传进第一层。
- **闭包晚绑定**：`[lambda: i for i in range(3)]` 三个 lambda 引用同一个变量 `i`，调用时循环已结束、`i` 是 2，得到 `[2, 2, 2]`；用默认参数 `lambda i=i: i` 在定义瞬间烙住当前值。
- **在装饰器本体（第二层）里写执行逻辑**：import 时就执行了，通常不是你想要的。
