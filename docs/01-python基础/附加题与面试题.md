# 模块 01 · Python 基础进阶练习与面试回顾

基础文件末尾的 `练习 TODO` 完成后，再做本页对应章节的附加题。建议每道题单独创建一个 `.py` 文件，先写出能运行的版本，再补充边界条件、函数拆分和测试样例。

## 01.1 语法基础：变量、类型与转换

### 附加题

1. **账单分摊器**：输入总金额、人数和服务费比例，计算每人应付金额，结果保留 2 位小数。处理人数必须大于 0、金额不能为负数。
2. **安全输入函数**：编写 `read_number(prompt, number_type=float)`，持续读取输入，直到用户输入合法数字；函数不能因为一次错误输入而退出。
3. **单位换算器**：支持摄氏度/华氏度、千米/英里、公斤/磅三组转换，用户输入转换类型和数值后输出结果。

### 面试回顾

- Python 的变量保存的是什么？`a = b` 后两个变量有什么关系？
- `is` 与 `==` 的区别是什么？什么时候应该使用 `is`？
- 为什么 `bool("False")` 的结果是 `True`？哪些常见值会被转换为 `False`？
- `int(3.99)` 的结果是什么？它和四舍五入有什么区别？

## 01.2 控制流：条件与循环

### 附加题与算法题

1. **猜数字游戏**：随机生成 1~100 的数字，最多猜 7 次；每次提示“大了/小了”，结束时显示次数和答案。
2. **质数筛选**：输入一个整数 `n`，输出 2~`n` 中全部质数。先写试除法，再尝试用“埃拉托斯特尼筛法”优化。
3. **文本菜单程序**：实现待办清单菜单：新增、查看、完成、删除、退出。菜单循环运行，输入错误时给出提示。

### 面试回顾

- `for` 循环和 `while` 循环分别适合什么场景？
- `break`、`continue`、`pass` 的作用有什么不同？
- 如何避免 `while` 无限循环？写出至少两种方法。
- `range(1, 10, 2)` 会产生哪些数字？`range` 是否会立即创建完整列表？

## 01.3 数据结构：列表、元组、字典与集合

### 附加题与算法题

1. **成绩分析器**：输入多名学生及成绩，使用字典保存数据，输出平均分、最高分、最低分和排名；成绩相同时排名并列。
2. **列表去重保序**：实现 `unique(items)`，去除重复元素但保留第一次出现的顺序，并说明元素不可哈希时如何处理。
3. **两数之和**：给定整数列表和目标值，返回两个元素的下标；要求平均时间复杂度为 `O(n)`，不能使用双重循环。
4. **词频统计**：读取一段文本，忽略大小写和标点，输出出现次数最多的 10 个单词。

### 面试回顾

- 列表和元组的主要区别是什么？为什么元组可以作为字典的键？
- 字典查找为什么通常是 `O(1)`？它依赖什么数据结构？
- 集合如何实现去重？集合中的元素需要满足什么条件？
- 浅拷贝和深拷贝有什么区别？请用嵌套列表举例说明。
- 列表推导式的优点和潜在问题是什么？

## 01.4 函数：参数、作用域与复用

### 附加题与算法题

1. **函数式计算器**：编写加减乘除函数，通过字典把运算符映射到函数；除数为 0 时返回明确错误。
2. **装饰器计时**：编写 `@timer` 装饰器，打印函数执行耗时，并保持原函数名称和文档字符串。
3. **递归与迭代**：分别实现阶乘、斐波那契数列和目录遍历，比较递归与迭代的可读性、性能及栈深度限制。
4. **可配置统计函数**：实现 `summarize(numbers, *, round_digits=2)`，返回数量、总和、平均值、中位数和极差。

### 面试回顾

- 位置参数、关键字参数、默认参数、`*args` 和 `**kwargs` 如何配合？
- 为什么不建议使用列表作为默认参数？如何修复？
- 局部变量、全局变量和 `nonlocal` 的查找规则是什么？
- 闭包是什么？闭包如何保存外层函数的变量？
- 可变对象作为参数传入函数时，函数内部修改会产生什么影响？

## 01.5 字符串与文件

### 附加题与算法题

1. **日志分析器**：读取日志文件，统计每个级别（INFO/WARN/ERROR）的数量，并输出出现最多的错误信息。
2. **CSV 成绩汇总**：读取 CSV 文件，跳过格式错误的行，计算每位学生的平均分并写入新的 CSV 文件。
3. **回文与最长单词**：忽略大小写、空格和标点，判断文本是否为回文；同时输出最长单词及其长度。
4. **大文件处理**：改写文本统计程序，使用逐行迭代方式处理文件，说明为什么不应一次性把超大文件全部读入内存。

### 面试回顾

- `str` 在 Python 中为什么不可变？修改字符串时实际发生了什么？
- `split()`、`join()`、`replace()` 的典型使用场景是什么？
- `with open(...)` 做了什么？为什么比手动 `open` / `close` 更安全？
- 文本文件的编码是什么？UTF-8 读写乱码时应该检查哪些地方？
- `read()`、`readline()`、`readlines()` 的区别是什么？

## 01.6 模块与包

### 附加题

1. **拆分命令行工具**：把待办清单拆成 `models.py`、`storage.py`、`cli.py`，使用 `main()` 作为程序入口。
2. **创建可复用包**：创建 `utils/` 包，包含日期、文本和数字三个子模块，在 `__init__.py` 中暴露公共函数。
3. **命令行参数**：使用标准库 `argparse` 支持 `add`、`list`、`remove` 子命令，并为参数写帮助信息。

### 面试回顾

- `import module`、`from module import name` 和 `import module as alias` 有什么区别？
- Python 如何查找被导入的模块？`sys.path` 起什么作用？
- 为什么要写 `if __name__ == "__main__":`？
- 包中的 `__init__.py` 有什么作用？现代 Python 中它是否总是必须？
- 循环导入为什么会出问题？如何通过拆分模块或延迟导入解决？

## 01.7 异常处理

### 附加题

1. **健壮的计算器**：处理非法数字、除数为 0 和未知运算符；错误信息要让用户知道如何修正输入。
2. **文件批处理**：批量读取目录中的文本文件，单个文件失败时记录错误并继续处理其他文件，最后汇总成功与失败数量。
3. **自定义异常体系**：为银行账户定义 `InsufficientBalanceError`、`InvalidAmountError`，在转账业务中分别抛出并捕获。
4. **重试机制**：编写 `retry(attempts)` 装饰器，对可能失败的函数自动重试，并在最终失败时保留原始异常。

### 面试回顾

- `try`、`except`、`else`、`finally` 的执行顺序是什么？
- 为什么应该捕获具体异常，而不是直接捕获 `Exception` 或裸 `except`？
- `raise` 和 `raise from` 有什么区别？
- 异常和返回错误码各有什么适用场景？
- 如何设计有意义的自定义异常？异常消息应包含哪些信息？

## 模块综合挑战：命令行学习任务管理器

完成基础章节后，独立实现一个不依赖第三方包的 CLI 程序，要求：

- 使用字典或数据类表示任务，字段至少包含标题、状态、优先级、创建时间。
- 支持新增、列表筛选、完成、删除和关键词搜索。
- 数据持久化到 JSON 文件，程序重启后数据仍然存在。
- 对用户输入、文件不存在、JSON 损坏等情况进行异常处理。
- 按模块拆分代码，并提供 `--help` 和至少 5 个手工测试场景。

### 综合面试回顾

- 如果任务数量从几百增长到几十万，当前数据结构和 JSON 存储会遇到什么问题？
- 如何给这个项目补充自动化测试？哪些函数最值得优先测试？
- 如何让业务逻辑和命令行输入输出解耦，以便未来接入 FastAPI？
- 哪些地方可以使用类型注解、数据类或生成器提升可读性和可维护性？
