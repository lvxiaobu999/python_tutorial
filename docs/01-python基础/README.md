# 模块 01 · Python 基础

> 目标：掌握 Python 核心语法，能独立写出小程序。

## 章节清单

| 章节 | 主题 |
|------|------|
| 01.1 语法基础 | 变量、数字/字符串/布尔、类型转换、注释 |
| 01.2 控制流 | if/elif/else、for、while、break/continue |
| 01.3 数据结构 | list、tuple、dict、set、切片、推导式 |
| 01.4 函数 | 定义与调用、参数、作用域、lambda |
| 01.5 字符串与文件 | 字符串方法、f-string、文件读写、with |
| 01.6 模块与包 | import、__name__、标准库 |
| 01.7 异常处理 | try/except/finally、自定义异常 |

## 学习要点

- **数据结构是重中之重**：list/dict 的增删查、推导式要练到本能反应。
- **函数参数**：`*args`/`**kwargs`、默认参数陷阱（可变默认值）要理解透。
- **文件用 `with`**：养成上下文管理器习惯，避免忘关文件。

## 练习方向

命令行小工具：待办清单、单词统计、猜数字、通讯录。
