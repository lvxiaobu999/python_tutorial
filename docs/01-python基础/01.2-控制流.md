## 核心概念

- **条件分支**：`if / elif / else` 让程序按条件走不同路；自上而下逐个判断，命中一个分支就不再看后面。
- **缩进即代码块**：Python 用缩进（通常 4 个空格）表示哪些代码属于同一个块，不是靠大括号。
- **组合条件**：`and`（且）、`or`（或）、`not`（非）把多个比较连起来；一行版判断用三元表达式 `值A if 条件 else 值B`。
- **range(start, stop, step)**：产生一串整数控制循环次数，**左闭右开**（含 start 不含 stop），且是**惰性**的——迭代到哪个才产生哪个，省内存。
- **for vs while**：知道循环几次用 `for i in range(n)`；不知道几次（如猜数字直到猜对）用 `while 条件`。
- **break / continue**：`break` 立即结束整个循环；`continue` 只跳过本轮剩余代码，进入下一轮。

## 关键代码

```python
# if / elif / else：自上而下匹配，命中即停
score = 86
if score >= 90:
    level = "A"
elif score >= 60:
    level = "B"
else:
    level = "C"
print(level)                          # B

# range 左闭右开：包含 1，不包含 6
total = 0
for number in range(1, 6):
    total += number                   # += 等价于 total = total + number
print("1 到 5 的和：", total)

# while：每轮都要有机会改变条件，否则死循环
count = 3
while count > 0:
    print("倒计时", count)
    count -= 1

# continue 只跳过本轮：偶数被跳过，只剩奇数
for number in range(1, 11):
    if number % 2 == 0:
        continue
    print("奇数：", number)
```

## 常见坑

- **`range(1, 6)` 不含 6**：想拿 1~5 却写成 `range(1, 5)`，只会拿到 1~4，记住右端是「停止值」。
- **while 忘了更新条件 → 死循环**：循环体里必须有让条件趋向 False 的语句（如 `count -= 1`），否则停不下来。
- **`=` 和 `==` 混用**：`=` 是赋值，`==` 是判断相等；条件里写 `=` 不是 Python 的写法，判断一律用 `==`。
- **缩进错位 = 代码归错块**：本该在循环里的语句少缩进一格，就跑到循环外了，只执行一次。
