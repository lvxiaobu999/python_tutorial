# 01.6 · 模块与包

> 练习代码：[01-模块导入.py](../../projects/01-python基础/01.6-模块与包/01-模块导入.py) · [calculator.py](../../projects/01-python基础/01.6-模块与包/calculator.py)

## 核心概念

- **一个 `.py` 文件就是一个模块**：导入后用「模块名.成员名」访问其中的函数、类、常量，复用代码不必重写。
- **两种导入方式**：`import math` 导入整个模块（用 `math.pi` 访问）；`from datetime import date` 只导入指定成员（直接写 `date.today()`）；`as` 可起别名。
- **模块搜索靠 `sys.path`**：Python 按它查找模块，项目目录、标准库、虚拟环境都会影响搜索结果。
- **包 = 模块的目录**：多个模块组成包，`__init__.py` 用于初始化包并暴露公共 API（本章节目录里就有一个）。
- **入口保护**：直接运行文件时 `__name__` 等于 `"__main__"`，被导入时不等于——把程序入口放进 `if __name__ == "__main__":`，可避免导入时意外执行命令行代码。
- **拆模块的时机**：同一段逻辑被多处使用（如计算器函数），就拆到独立模块再 import。

## 关键代码

```python
import math
import random
from datetime import date
from calculator import multiply      # 导入同目录自己写的模块

print("圆面积：", math.pi * 3 ** 2)   # import 导入后必须用 模块名.成员
print("随机数：", random.randint(1, 10))   # randint 含头含尾
print("今天：", date.today())          # from 导入后直接写成员名
print(multiply(6, 6))

# 入口保护：直接运行才执行，被导入时不执行
if __name__ == "__main__":
    print("直接运行当前文件")
```

```text

36

```

## 常见坑

- **`import math` 后直接写 `pi` 报 NameError**：import 导入的是模块本身，成员要经 `math.pi` 访问；想省前缀就 `from math import pi`。
- **没有入口保护，模块被导入时顶层代码照跑**：命令行程序、input() 之类的代码若不放进 `if __name__ == "__main__":`，别人一 import 就会被执行。
- **自建文件名别和标准库撞车**：搜索按 `sys.path` 进行，项目目录、标准库、虚拟环境都参与；把文件命名成 `random.py` 这类会干扰导入结果。
- **`from calculator import multiply` 找不到模块**：确认被导入模块和运行脚本在同一目录（或已在 `sys.path` 上）。
