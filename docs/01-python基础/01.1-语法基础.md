## 核心概念

- **变量是标签不是盒子**：`变量名 = 值` 让名字指向内存中的一个对象；变量本身没有类型，值才有类型。
- **动态类型**：同一个变量可以先后指向不同类型的对象（先存 `10` 再存 `"文本"` 都合法），`type(x)` 随时查看当前类型。
- **四种基本类型**：`int` 整数、`float` 浮点数、`str` 字符串、`bool` 布尔（`True`/`False`），计算、文本、判断全靠它们。
- **算术运算符分工**：`/` 普通除法且结果总是浮点数；`//` 整除（向下取整）；`%` 取余；`**` 幂。
- **类型转换是显式的**：`int()` / `float()` / `str()` / `bool()` 是内置构造函数，Python 不会自动把 `"5"` 当成 5 用。
- **命名约定**：字母/下划线开头，后跟字母/数字/下划线；风格用 `snake_case`（小写 + 下划线）。注释用 `#`（单行）或三引号（多行）。

## 关键代码

```python
# 算术运算：/ 结果是 float，// 整除，% 取余，** 幂
a, b = 10, 3
print(a / b, a // b, a % b, a ** b)   # 3.3333333333333335 3 1 1000

# 类型转换：int(3.99) 直接截断不四舍五入；空字符串转 bool 是 False
print(int(3.99), str(123), bool(""))  # 3 123 False

# input() 永远返回字符串，做计算前先转 int
raw = input("请输入年龄：")
age = int(raw)
print("明年", age + 1)
```

## 运行结果

```text
3.3333333333333335 3 1 1000
3 123 False
明年 26        # 输入 25 时
```

## 常见坑

- **数字 + 字符串直接拼接报错**：`"我有 " + 5` 抛 TypeError，`+` 只能同类型相加 → 改成 `"我有 " + str(5)`。
- **`/` 和 `//` 混淆**：`/` 是普通除法（结果总是 float），`//` 才是整数除法；想要整数结果别用 `/`。
- **`int(3.99)` 不是四舍五入**：小数部分直接截断得到 3，不是 4。
- **`input()` 不转换就算不了数**：返回的 `"25"` 是字符串，`"25" + 1` 会报错，先 `int()` / `float()`。
- **`bool("False")` 是 True**：非空字符串都是真值；假值只有 `0`、`0.0`、`""`、空容器和 `None`。
