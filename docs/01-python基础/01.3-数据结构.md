## 核心概念

- **四种容器一句话定位**：`list` 可变有序的序列；`tuple` 不可变有序、适合固定搭配；`dict` 键到值的映射；`set` 无序且自动去重。
- **列表**：`append` 尾加、`insert` 插入、`remove` 按值删、`pop` 按位置删并返回、`sort`/`reverse` 原地排序反转；索引从 0 开始。
- **切片 `[start:stop:step]`**：取子序列，不含 stop；`[::-1]` 是反转的标准写法，切片越界不报错。
- **元组**：不能增删改；支持解包 `x, y = point`；单个元素必须写 `(5,)` 带逗号。
- **字典**：`d[key]` 取值（键不存在抛 KeyError），`d.get(key, 默认值)` 兜底不报错；`.items()` 遍历键值对。
- **集合**：定义时自动去重；`&` 交集、`|` 并集、`-` 差集、`^` 对称差；`remove` 删不存在的值报错，`discard` 不报错。

## 关键代码

```python
# 列表：可变有序，索引从 0 开始
fruits = ["apple", "banana", "orange"]
fruits.append("pear")             # 末尾添加
fruits[1] = "grape"               # 按索引修改
print(fruits[:2])                 # ['apple', 'grape']，切片不含 stop
print(fruits[::-1])               # 反转

# 元组：不可变 + 解包
point = (10, 20)
x, y = point                      # x=10, y=20

# 字典：键值映射，get 兜底不报错
user = {"name": "小明"}
user["city"] = "北京"             # 新增/修改都是 [key] = value
print(user.get("email", "未填写"))

# 集合：自动去重 + 交集
tags = {"python", "ai", "python"} # 去重后只剩 2 个
print(tags & {"ai", "web"})       # 只保留两边都有的
```

## 运行结果

```text
['apple', 'grape']
['pear', 'orange', 'grape', 'apple']
未填写
{'ai'}
```

## 常见坑

- **`{}` 是空字典不是空集合**：要建空集合必须写 `set()`，写 `{}` 拿到的是 dict。
- **单元素元组必须带逗号**：`(5)` 只是数字 5，`(5,)` 才是元组。
- **`remove(x)` 删不存在的值会报错**：集合里改用 `discard(x)` 删不存在的值不报错；列表删除前可先 `in` 判断。
- **别拿内置函数名当变量名**：`max` / `min` / `list` / `dict` 被赋值后就覆盖了内置功能，后面再调 `max()` 会报错。
- **索引从 0 开始、切片不含 stop**：`fruits[:2]` 取第 0、1 个元素，不包含索引 2，和 `range` 一样左闭右开。
