# 01.4 · 函数

> 练习代码：[01-函数基础.py](../../projects/01-python基础/01.4-函数/01-函数基础.py) · [02-函数参数.py](../../projects/01-python基础/01.4-函数/02-函数参数.py)

## 核心概念

- **函数 = 封装可复用逻辑**：`def` 定义，函数名加括号调用；参数是输入，`return` 把结果交还调用者，没有 `return` 时返回 `None`。
- **定义顺序口诀**：位置参数 → 默认参数 → `*args` → `**kwargs`，按这个顺序写就不会乱。
- **`*args` / `**kwargs` 收集**：定义时 `*args` 把多余的位置参数收集成元组，`**kwargs` 把多余的关键字参数收集成字典。
- **调用时 `*` / `**` 展开**：`f(*列表)` 拆开按位置传，`f(**字典)` 拆开按名字传——和定义时的「收集」正好相反。
- **默认值只在定义时创建一次**：默认参数不是每次调用都新建，这是可变默认参数陷阱的根源。
- **作用域**：函数内赋值的变量是局部变量；`nonlocal` 修改外层函数变量，`global` 修改模块变量。

## 关键代码

```python
def average(*args):                    # *args 把多余位置参数收集成元组
    return sum(args) / len(args) if args else 0

print("平均分：", average(80, 90, 100))

# 陷阱：默认值在「函数定义时」只创建一次，所有调用共享同一个列表
def add_item_bad(item, bag=[]):        # ❌ 上次 append 的元素还在
    bag.append(item)
    return bag

def add_item_good(item, bag=None):     # ✅ 惯用写法：None 占位，调用时才新建
    if bag is None:
        bag = []
    bag.append(item)
    return bag

print(add_item_bad("苹果"), add_item_bad("苹果"))
print(add_item_good("苹果"), add_item_good("苹果"))
```

## 运行结果

```text
平均分： 90.0
['苹果', '苹果'] ['苹果', '苹果']     # 共享同一列表，越攒越多
['苹果'] ['苹果']                     # 每次独立新建
```

## 常见坑

- **可变默认参数在多次调用间共享**：默认值定义时只创建一次，`bag=[]` 会让历史记录越攒越多 → 惯用 `None` 占位、函数体内新建。
- **位置传参顺序错了值就跟着错**：`introduce(name, city)` 按 `("北京", "小明")` 传会张冠李戴；不怕顺序乱就用关键字传参。
- **位置参数必须写在关键字参数前面**：混合传参时先报位置再报名字，`f(name="x", "y")` 会报语法错误。
- **`*` 之后的参数只能按名字传**：`def f(name, *, is_admin=False)` 里 `f("小明", True)` 抛 TypeError，必须写 `is_admin=True`，可防止调用者靠位置传错值。
- **忘了 `return` 就拿到 None**：函数默认返回 `None`，调用方拿到结果去运算会报错。
