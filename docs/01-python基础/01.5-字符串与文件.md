# 01.5 · 字符串与文件

> 练习代码：[01-字符串操作.py](../../projects/01-python基础/01.5-字符串与文件/01-字符串操作.py) · [02-文件读写.py](../../projects/01-python基础/01.5-字符串与文件/02-文件读写.py)

## 核心概念

- **字符串是不可变序列**：`strip()` / `upper()` / `replace()` 等全部返回**新字符串**，原串纹丝不动，所以必须用变量接住返回值。
- **清理与大小写**：`strip()` 只去首尾空白；`lower()` / `upper()` 统一大小写，统计前先统一才不漏。
- **`split` 与 `join` 互为逆操作**：拆分用 `s.split(分隔符)`，拼接用 `分隔符.join(列表)`；循环里用 `join` 比 `+` 快（`+` 每轮都创建新串）。
- **切片与成员判断**：`s[0:6]` 不含 stop，`s[::-1]` 反转；`in` 既是判断（`"py" in s`）也是遍历（`for ch in s`）。
- **pathlib 读写小文件**：`Path.write_text()` / `read_text()` 一次读写整个文件，是「覆盖」语义；`splitlines()` 按行拆且自动去换行符。
- **with + 逐行处理**：大文件友好、内存占用小；`with` 块结束自动关闭文件，中途抛异常也会关，永远优先用 with。

## 关键代码

```python
from pathlib import Path

# 字符串不可变：方法返回新串，必须用变量接住
clean = "  hi AI  ".strip()
print(clean.replace("AI", "人工智能"))    # hi 人工智能
print("hello_world".split("_"))           # ['hello', 'world']

# with 逐行读：行尾带 \n，常配 strip() 去掉；encoding 明确写 utf-8
path = Path("notes.txt")
with path.open("r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
```

## 运行结果

```text
hi 人工智能
['hello', 'world']
（逐行打印 notes.txt 的内容，每行已去掉首尾空白和换行符）
```

## 常见坑

- **调了方法不接返回值**：`text.strip()` 单独一行等于白做，原字符串没有任何变化（不可变性）→ 必须 `clean = text.strip()`。
- **`split()` 无参和 `split("_")` 行为不同**：无参按任意连续空白拆并丢弃空串；指定分隔符时连续分隔符会产生空串（`"a__b".split("_")` 中间有个 `""`）。
- **回文题里 `strip()` 只去首尾**：要忽略**所有**空格得用 `s.replace(" ", "")` 或 `"".join(s.split())`。
- **大小写敏感统计忘了先 `lower()`**：元音、词频统计会漏掉大写字母，先统一大小写再数。
- **`"w"` 模式一打开就清空文件**：它是覆盖写入、先清空原内容；想接着写用 `"a"` 追加模式（`write_text()` 没有追加参数）。
- **Windows 默认编码是 GBK**：处理中文必须写 `encoding="utf-8"`，否则乱码或 `UnicodeDecodeError`。
- **相对路径跟着运行目录走**：相对的是运行命令时所在的目录，不是 .py 文件所在目录；想相对脚本定位用 `Path(__file__).parent`。
