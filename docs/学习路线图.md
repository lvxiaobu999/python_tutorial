# 学习路线图

> 一条从零到能独立构建「FastAPI + LangChain + LangGraph + 前端」AI 应用的推荐路径。
> 与 [教程大纲.md](./教程大纲.md) 配套：大纲讲「学什么」，路线图讲「按什么顺序学、花多久、里程碑是什么」。

---

## 一、路线总览

```
阶段 0         阶段 1         阶段 2         阶段 3         阶段 4
环境搭建  ──▶  Python 基础 ──▶ Python 进阶 ──▶ FastAPI 基础 ──▶ FastAPI 进阶
(1周)          (3~4周)         (2~3周)         (2周)           (2~3周)
                                                                  │
   阶段 5         阶段 6         阶段 7         阶段 8         阶段 9   │
前端 AI 应用 ──▶ LangChain 基础 ──▶ LangChain 进阶 ──▶ LangGraph ──▶ 项目实战 ◀──┘
(1~2周)         (2周)           (2~3周)          (2~3周)        (3~4周)
```

> ⚠️ 两条前置链：**Python 基础/进阶是 FastAPI 的前置**，**FastAPI + LangGraph 是项目实战的前置**。
> LangChain / LangGraph 可以提前到 FastAPI 基础之后并行学（它们主要依赖 Python，不依赖 Web 框架）。

## 二、分阶段说明

### 阶段 0 · 环境搭建（约 1 周）
- **前置**：无
- **产出**：能用 `uv` 创建项目、加依赖、跑通 Hello World；VSCode 配好格式化与调试；Git 能提交。
- **关键内容**：uv 初始化与依赖管理 → [00-环境搭建/uv使用指南.md](./00-环境搭建/uv使用指南.md)
- **验收**：`uv run python -c "print('hello')"` 正常输出。

### 阶段 1 · Python 基础（约 3~4 周）
- **前置**：阶段 0
- **产出**：掌握语法、控制流、数据结构、函数、异常，能写小程序。
- **验收**：独立完成一个命令行小工具（如待办清单、单词统计）。

### 阶段 2 · Python 进阶（约 2~3 周）
- **前置**：阶段 1
- **产出**：掌握 OOP、类型注解、异步、测试。
- **重点**：类型注解与 asyncio 是理解 FastAPI 的关键，务必吃透。
- **验收**：用 `pytest` 为一个小模块写完整测试；理解 `async def` 路由为何能非阻塞。

### 阶段 3 · FastAPI 基础（约 2 周）
- **前置**：阶段 2
- **产出**：能写带 Pydantic 校验、依赖注入的 REST API，会用自动文档。
- **验收**：实现一个 CRUD 接口（内存存储即可）。

### 阶段 4 · FastAPI 进阶（约 2~3 周）
- **前置**：阶段 3
- **产出**：掌握数据库、JWT 认证、中间件、WebSocket、部署。
- **验收**：一个带数据库和登录鉴权的完整 API，能用 Docker 跑起来。

### 阶段 5 · 前端 AI 应用（约 1~2 周）
- **前置**：阶段 3（会调 API 即可，可并行于阶段 4）
- **产出**：用 Streamlit 做一个可视化界面，支持流式输出。
- **验收**：前端能流式展示后端返回的对话内容。

### 阶段 6 · LangChain 基础（约 2 周）
- **前置**：阶段 2（Python 熟练即可，可并行于阶段 3/4）
- **产出**：理解 Model/Prompt/Chain 抽象，会用 LCEL 写链式调用。
- **验收**：写一个带记忆的对话脚本。

### 阶段 7 · LangChain 进阶（约 2~3 周）
- **前置**：阶段 6
- **产出**：能构建 RAG 与 Agent，掌握可观测与调试手段。
- **验收**：本地跑通一个「上传文档 → 问答」的 RAG 应用。

### 阶段 8 · LangGraph（约 2~3 周）
- **前置**：阶段 7
- **产出**：能构建可循环、带状态、可人工干预的 Agent 工作流。
- **重点**：`StateGraph`、条件边（循环）、Checkpoint 持久化、Human-in-the-loop、多 Agent。
- **验收**：跑通一个「带人工审批步骤的多步 Agent 工作流」。

### 阶段 9 · 项目实战（约 3~4 周）
- **前置**：阶段 4 + 阶段 8
- **产出**：一个完整全栈 AI 应用（后端 FastAPI + LangChain/LangGraph + 前端 + 部署）。
- **验收**：部署上线，可对外访问。

## 三、里程碑与时间估算

| 里程碑 | 阶段 | 累计约 | 可交付物 |
|--------|------|--------|----------|
| 环境就绪 | 0 | 1 周 | 可运行的项目骨架 |
| 会写 Python | 1 | 4~5 周 | 命令行小工具 |
| 理解类型与异步 | 2 | 7 周 | 带测试的模块 |

| 会做界面 | 5 | 13 周 | Streamlit 界面 |

## 四、学习方法建议

1. **每个模块产出笔记**：用 AI 辅助（见根目录 `CLAUDE.md` / `AGENTS.md`）把当次学习的要点写成笔记，落到对应模块目录。
2. **每阶段一个小项目**：不满足于看懂，必须动手跑通「验收」那一项。
3. **代码进 `projects/`**：练习代码统一放 `projects/<模块编号>-<名字>/`，与笔记分离。
4. **遇到报错先自查**：让 AI 帮你「定位+解释」而不是直接给答案，这样学得更牢。
5. **LangChain/LangGraph 与 FastAPI 可并行**：前者只依赖 Python，后者是 Web 框架，可以错峰推进节省时间。
