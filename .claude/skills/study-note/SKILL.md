# 学习笔记技能（study-note）

把刚学完的一个知识点，整理成一篇规范的学习笔记，存到 `docs/` 对应的模块目录下。

## 何时使用

- 用户说「记录笔记 / 总结这一课 / 写学习笔记 / 整理一下这个知识点」。
- 或学完一个章节后，用户想沉淀要点。

## 步骤

1. **确定模块与章节号**
   - 打开 `docs/教程大纲.md`，找到该知识点所属的「模块」和「章节号」（如 `03.5 依赖注入`）。
   - 模块对应目录：`docs/03-fastapi基础/` 这类。用大纲里的模块编号映射（00~08）。

2. **确定文件路径**
   - 命名：`<章节号>-<主题>.md`，例如 `docs/03-fastapi基础/03.5-依赖注入.md`。
   - 主题用短横线连接的小写英文或中文皆可，但要简洁。

3. **用以下模板生成笔记**（内容用中文）：

```markdown
# <章节号> · <主题>

## 核心概念
（这个知识点是什么、解决什么问题、用在什么场景）

## 关键代码
```python
# 最小可运行示例，附必要注释
```

## 运行结果
（贴实际输出，或说明预期行为）

## 常见坑
- （踩过的坑 + 原因 + 解决办法）

## 下一步
（关联到后续章节或模块，用相对链接）
```

4. **写完后**：在所属模块的 `README.md` 里若有必要，补充该章节一行；不要改动 `教程大纲.md` 的结构。

## 注意事项

- 笔记是「学习沉淀」，要短而精，不要复制整段教程；突出「核心概念 + 最小代码 + 踩坑」。
- 代码块必须标注语言（`python`、`bash` 等）。
- 如果知识点跨多个章节，选最相关的一个模块目录，其余用「下一步」互相链接。
- 若 `projects/` 里有对应练习代码，用相对路径链过去（如 `../../projects/03-xxx/`）。
