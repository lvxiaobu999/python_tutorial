# 模块 03 · FastAPI 基础 — 练习代码

对应教学大纲见 [docs/03-fastapi基础](../../docs/03-fastapi基础/README.md)。

> 目标：能写一个带参数校验、数据模型、依赖注入的 REST API。
> 路线图验收标准：实现一个 CRUD 接口（内存存储即可）。
> 前置呼应：02.4 的类型注解在路由签名上「开始干活」；02.5 的异步解释了 `async def` 路由为何能扛并发。

## 运行方式

在 `projects/03-fastapi基础` 目录下（uv 会自动用本项目的 .venv）：

```bash
uv run fastapi dev "03.1-快速开始/01-快速开始.py"   # 开发服务器，改代码自动重载
```

启动后浏览器打开 <http://127.0.0.1:8000/docs>——这是自动生成的接口文档，可以直接 Try it out。`Ctrl+C` 停止。

> ⚠️ 不能用 `uv run python xxx.py` 起 FastAPI 应用：那只定义了 `app`，不会监听端口。起服务交给 `fastapi dev` / `uvicorn`。

## 推荐学习顺序

1. **03.1**：跑通第一个 API，玩转 /docs——建立「写函数就是写接口」的手感。
2. **03.2**：路由三件套（路径/查询/请求体）是骨架，每章都在用它。
3. **03.3**：Pydantic 是灵魂，02.4 的注解在这里兑现成自动校验。
4. **03.4 / 03.5**：响应模型管「出口」，依赖注入管「公共逻辑」，FastAPI 最独特的两件套。
5. **03.6**：错误处理收尾，然后直接进大作业。

## 期末综合大作业（模块验收）

**图书管理 API**（内存存储，不需要数据库）：

| 要求 | 涉及章节 |
|------|---------|

验收方式：启动服务后，在 /docs 里把增删改查全流程点一遍，非法输入能被 422 拦下、不存在的 id 返回 404。
