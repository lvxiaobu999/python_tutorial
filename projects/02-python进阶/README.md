# 模块 02 · Python 进阶 — 练习代码

对应笔记见 [docs/02-python进阶](../../docs/02-python进阶/README.md)。

> 目标：掌握**面向对象、类型注解与异步**，为 FastAPI 打基础。
> 路线图验收标准：① 用 pytest 为一个小模块写出完整测试；② 能说清 `async def` 路由为何非阻塞。

## 运行方式

在 `projects/02-python进阶` 目录下用 `uv run`：

```bash
uv run python "02.1-面向对象/01-类与继承.py"   # 运行某一章的演示+练习
uv run pytest "02.7-测试" -v                   # 跑测试（第 7 章起）
```

> 本章起项目多了 `pytest`（dev 依赖）。依赖管理本身就是 02.6 的学习内容，边用边体会。

## 章节与目录结构

```
02-python进阶/
```

## 推荐学习顺序

1. **02.1 → 02.2 → 02.3**：对象模型一条线（类 → 装饰器本质是函数 → 生成器是特殊的迭代器）。
2. **02.4**：类型注解，越早养成习惯越好，后面所有代码都要求带注解。
3. **02.5**：异步是本模块的重头戏，也是 FastAPI 高并发的根基，多花时间。
4. **02.6**：概念 + 命令实践，可穿插在任何时候做（半天即可）。
5. **02.7**：测试放最后，学完立刻给前面的练习补测试，形成闭环。

每章的学习方式与模块 01 相同：先读章节 `README.md` 的「知识点速查」，再跑演示代码、完成文件末尾的「练习 TODO」。
