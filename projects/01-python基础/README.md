## 运行方式

在 `projects/01-python基础` 目录下，用 `uv run` 运行任意练习文件：

```bash
uv run python main.py
uv run python "01.1-语法基础/01-变量与注释.py"
```

> 提示：本项目用 `uv` 管理，不需要手动 `pip install`。首次运行 `uv run` 会自动创建 `.venv` 虚拟环境。

## 学习方式

1. 先通读每个文件的注释，理解每行在做什么。
2. 自己运行，对照输出。
3. 完成文件末尾的「练习 TODO」，遇到不会的可以问我或让 AI 讲解。
