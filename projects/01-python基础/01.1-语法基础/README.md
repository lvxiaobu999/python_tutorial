# 01.1 语法基础

> 这一章解决「Python 里怎么存数据、有哪些类型、怎么转换」，是所有程序的地基。

## 知识点速查

### 1. 变量与赋值
- 语法：`变量名 = 值`，**变量没有类型，值才有类型**。
- 命名：字母/下划线开头，后跟字母/数字/下划线；约定 `snake_case`（小写 + 下划线）。
- 动态类型：同一个变量可以先后存不同类型的值。
- `type(x)` 查看 x 的类型。

### 2. 数据类型
| 类型 | 写法 | 例子 | 常用操作 |
|------|------|------|----------|
| 整数 int | `10` | 没有小数点 | `+ - * / // % **` |
| 浮点数 float | `3.14` | 有小数点 | 同上 |
| 字符串 str | `"hi"` / `'hi'` | 文本 | `+` 拼接、`*` 重复、`len()` |
| 布尔 bool | `True` / `False` | 真假 | 比较、`and`/`or`/`not` |

- 算术：`/` 结果**总是浮点数**；`//` 整除；`%` 取余；`**` 幂。
- 字符串：`"a" + "b"` → `"ab"`；`"哈" * 3` → `"哈哈哈"`；`len("abc")` → 3。

### 3. 类型转换
- `int("123")` → 123；`int(3.99)` → 3（**截断，不四舍五入**）
- `float("3.14")` → 3.14；`float(10)` → 10.0
- `str(123)` → "123"
- `bool(0)` / `bool("")` → False；`bool(1)` / `bool("abc")` → True
- `input()` 永远返回**字符串**，要算数得先 `int()` / `float()` 转换。

### 4. 注释
- 单行：`# 注释`
- 多行：`""" 注释 """` 或 `''' 注释 '''`

## 易错点
- 数字 + 字符串直接拼接会报错：`"我有 " + 5` ❌ → `"我有 " + str(5)` ✅
- `/` 是普通除法（结果是 float），`//` 才是整数除法。

## 进阶
变量是指向对象的名称，Python 会根据赋值推断类型；`type()` 可查看类型。数字支持 `+ - * / // % **`，字符串支持拼接、重复、索引和切片，`bool()` 会按真值规则转换；`input()` 的返回值永远是字符串，计算前要转换为 `int` 或 `float`。
