# 01.4 函数

函数把一段逻辑封装起来，使用 `def` 定义、使用函数名加括号调用。参数是输入，`return` 是输出；没有 `return` 时返回 `None`。

`*args` 把多余的位置参数收集成元组，`**kwargs` 把多余的关键字参数收集成字典。参数后的 `*` 可强制关键字传参。函数内部变量通常是局部变量；`nonlocal` 修改外层函数变量，`global` 修改模块变量。不要使用列表作为默认参数，因为它会在多次调用之间共享。

## 参数与作用域

位置参数按出现顺序绑定，关键字参数按参数名绑定；默认参数可以省略。`*args` 把多余的位置参数收集成元组，`**kwargs` 把多余的关键字参数收集成字典。函数内部变量通常是局部变量；`nonlocal` 修改外层函数变量，`global` 修改模块变量。不要使用列表作为默认参数，因为它会在多次调用之间共享。
