# 01.6 模块与包

一个 `.py` 文件就是模块。`import math` 后用 `math.pi` 访问成员；`from datetime import date` 只导入指定成员；`as` 可设置别名。Python 会在 `sys.path` 中查找模块，项目目录、标准库和虚拟环境都会影响搜索结果。

多个模块组成包，`__init__.py` 可初始化包并暴露公共 API。直接运行文件时 `__name__ == "__main__"`，被导入时则不是；因此把程序入口放入 `if __name__ == "__main__":`，可避免导入时执行命令行代码。

## 学习顺序与练习

先运行示例，比较 `import` 和 `from ... import ...` 的调用方式，再把计算器拆成独立模块。完成基础 TODO 后，继续拆分一个可复用 CLI 包，并用 `argparse` 增加命令行参数；面试回顾重点是模块搜索路径、包初始化和循环导入。
