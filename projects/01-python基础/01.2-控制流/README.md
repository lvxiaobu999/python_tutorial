# 01.2 控制流

> 这一章解决「让程序做判断、重复执行」。核心是 `if` 判断、`for`/`while` 循环、`range`。

## 知识点速查

### 1. 条件判断 if / elif / else
```python
if 条件1:
    ...
elif 条件2:      # 可有多个，也可以没有
    ...
else:            # 可选
    ...
```
- 比较运算符：`> < >= <= == !=`
- 组合条件：`and`（且）、`or`（或）、`not`（非）
- 三元表达式（一行判断）：`结果A if 条件 else 结果B`

### 2. range() 是什么
`range(start, stop, step)` 产生一串**整数**，常用来控制循环次数。

- **左闭右开**：包含 start，不包含 stop。
- `range(5)` → 0, 1, 2, 3, 4（省略 start，默认从 0 开始）
- `range(1, 6)` → 1, 2, 3, 4, 5（1 到 5，**不含 6**）
- `range(1, 10, 2)` → 1, 3, 5, 7, 9（步长 2）
- **惰性**：range 不立刻把全部数造出来，迭代到哪个才产生哪个，很省内存。

### 3. for 循环
```python
for 变量 in 可迭代对象:   # range、列表、字符串等
    ...
```
- 固定次数用 `for i in range(n)`。
- 遍历列表想同时拿索引和值，用 `enumerate(列表)`。

### 4. while 循环
```python
while 条件:
    ...
```
- 条件为 True 就一直重复，**记得在循环里改变条件**，否则死循环。
- 适合「不知道要循环几次」的场景（比如猜数字直到猜对）。

### 5. break 和 continue
- `break`：**立即结束整个循环**。
- `continue`：**跳过本次**循环剩余代码，进入下一次。

## 易错点
- `range(1, 6)` 不含 6，别写成 `range(1, 5)` 想拿 1~5。
- while 忘了更新条件 → 死循环。
- `=` 是赋值，`==` 是判断相等，别混用。
